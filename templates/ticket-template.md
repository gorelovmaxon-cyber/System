## Контекст

[1-2 абзаца: что делаем и почему. Ссылка на раздел ТЗ/спеки.]

Пример:
```
В ТЗ v7 ревизия 3 резинки переименованы с абстрактных уровней (лёгкая/средняя/тяжёлая) 
на цвета (чёрная/жёлтая/красная/зелёная). Также добавлены упражнения 20 и 21, 
причём упр. 21 использует комбинацию из 3 резинок одновременно — новый тип поля выбора.
```

## Файлы для изменения

**Формат:** путь — что именно менять (функция/константа/строки)

```markdown
- `src/data.js` — строки 45-60, константа BAND_LEVELS → BAND_COLORS
- `src/workout.js` — функция `renderBandSelector()` (~строка 120)
- `src/ui-today.js` — упражнение 21, добавить `multiSelect: true` (~строка 85)
- `test/workout.test.js` — добавить тесты для getBandColor() и multiSelect
```

**Принцип:** Qwen должен точно знать, куда лезть. Указывай конкретные функции/константы, примерные строки.

## Алгоритм (шаг за шагом)

**Формат:** пронумерованные шаги с примерами "Было → Стало"

```markdown
1. В `src/data.js`:
   
   Было:
   ```javascript
   var BAND_LEVELS = ['лёгкая', 'средняя', 'тяжёлая'];
   function getBandLevel(index) { return BAND_LEVELS[index]; }
   ```
   
   Стало:
   ```javascript
   var BAND_COLORS = ['чёрная', 'жёлтая', 'красная', 'зелёная'];
   function getBandColor(index) { return BAND_COLORS[index]; }
   ```

2. В `src/workout.js`:
   - Найди все вызовы `getBandLevel()` (используй Ctrl+F)
   - Замени на `getBandColor()`
   - В функции `renderBandSelector()`: замени надпись "Уровень:" на "Цвет:"

3. В `src/ui-today.js`:
   - Найди объект упражнения 21 (тяга сидя)
   - Добавь поле `multiSelect: true` рядом с `bandRequired: true`
   
   Пример:
   ```javascript
   {
     id: 21,
     name: 'Тяга сидя',
     bandRequired: true,
     multiSelect: true,  // <-- новое поле
     sets: 4,
     // ...
   }
   ```

4. [продолжай для каждого файла...]
```

**Принцип:** 
- Один шаг = одна атомарная операция
- Показывай код "Было → Стало"
- Укажи, как найти нужное место (Ctrl+F, имя функции)

## Тесты должны проверить

**Формат:** список ожидаемого поведения + команда

```markdown
- `getBandColor(0)` возвращает `'чёрная'`
- `getBandColor()` без аргумента возвращает массив `['чёрная', 'жёлтая', 'красная', 'зелёная']`
- Упражнение 21 имеет `multiSelect === true`
- Упражнение 21 имеет `bandRequired === true` (не сломали старое)
- Все 199 тестов зелёные

Команда: `node --test` (БЕЗ аргумента test/ — на Windows Node 24 это баг)
```

**Принцип:** Чёткие критерии успеха, которые Qwen может проверить.

## Как закончить

**Формат:** точные команды + шаблон сообщения

```markdown
1. Проверь, что все файлы из списка изменены
2. Запусти `node --test` — должно быть 199/199 зелёные
3. Сделай коммит:
   ```bash
   git add -A
   git commit -m "T2: цвета резинок и упражнения 20, 21"
   ```

4. Сообщи пользователю:
   ```
   ✅ T2 готов
   Коммит: [hash из git log]
   Тесты: 199/199 зелёные
   Изменены: src/data.js, src/workout.js, src/ui-today.js
   ```
```

**Принцип:** Qwen не должен додумывать, что делать в конце.
