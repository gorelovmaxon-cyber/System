# Шаблон проверки для Opus

Используй этот шаблон при проверке результата работы Qwen.

---

# Review T[номер] — [Название тикета]

## Шаг 1: Запроси данные у пользователя

```
Для проверки T[номер] мне нужно:

1. git log --oneline -1
2. node --test
3. git diff HEAD~1 --stat

Запусти эти команды и пришли результат.
```

## Шаг 2: Проверь коммит

### A) Сообщение коммита
- [ ] Соответствует формату из тикета?
- [ ] Упоминает номер тикета (T2, T3...)?

**Пример:**
```
Тикет требовал: "T2: цвета резинок и упражнения 20, 21"
Коммит: "T2: цвета резинок и упражнения 20, 21" ✅
```

### B) Список изменённых файлов
```bash
# Из git diff HEAD~1 --stat
src/data.js       | 10 +++---
src/workout.js    |  5 +++
src/ui-today.js   |  3 ++
```

Проверь:
- [ ] Все файлы из тикета изменены?
- [ ] Нет лишних файлов (не указанных в тикете)?
- [ ] Нет изменений в тестах (если тикет не требовал)?

**Если есть лишние файлы:**
```
⚠️ Изменены файлы не из тикета: [список]
Запроси у пользователя: git diff HEAD~1 [файл]
Проверь, оправданы ли изменения.
```

## Шаг 3: Проверь тесты

### A) Количество тестов
```bash
# Из node --test
✔ ... (199 tests)
```

- [ ] Все 199 тестов зелёные?
- [ ] Нет пропущенных (skipped) тестов?

**Если есть красные:**
```
❌ Тесты красные: [сколько упало]
Запроси полный вывод: node --test 2>&1
```

### B) Новые тесты (если тикет требовал)
```
Тикет требовал тесты для:
- getBandColor() возвращает массив цветов
- Упражнение 21 имеет multiSelect === true
```

Проверь:
- [ ] Новые тесты добавлены в `test/`?
- [ ] Они проходят?

## Шаг 4: Проверь код (выборочно)

Запроси ключевые изменения:
```
git diff HEAD~1 src/data.js
```

Проверь 1-2 критичных изменения из тикета:
- [ ] Алгоритм выполнен правильно?
- [ ] Нет опечаток в константах/функциях?
- [ ] Нет очевидных багов (undefined, null)?

**Не проверяй весь код построчно** — только критичное.

## Шаг 5: Вынеси вердикт

### Вариант A: Всё ОК ✅

```
✅ T[номер] принят

Коммит: [hash] соответствует тикету
Тесты: 199/199 зелёные
Изменены: [список файлов из тикета]

Переходи к T[номер+1], передай его Qwen.
```

### Вариант B: Мелкие правки ⚠️

```
⚠️ T[номер] почти готов, нужны правки:

1. [конкретная проблема]
   Где: [файл:строка]
   Что исправить: [точное действие]

2. [конкретная проблема]
   Где: [файл:строка]
   Что исправить: [точное действие]

Передай Qwen: "Исправь в T[номер]: [список]"
Не делай новый коммит, правь в текущем через git commit --amend.
```

### Вариант C: Серьёзные проблемы ❌

```
❌ T[номер] не принят, нужна переделка

Проблемы:
1. [что не так]
2. [почему не соответствует тикету]

Действия:
git reset --hard HEAD~1  # откат коммита

Передай Qwen тикет T[номер] заново с уточнением:
"Предыдущая попытка не прошла:
- [проблема 1]
- [проблема 2]

Выполни тикет заново, учитывая это."
```

## Чеклист проверки

- [ ] Коммит соответствует формату?
- [ ] Все файлы из тикета изменены?
- [ ] Нет лишних изменений?
- [ ] 199/199 тестов зелёные?
- [ ] Новые тесты (если требовались) добавлены?
- [ ] Алгоритм выполнен правильно (выборочно)?

Если все ✅ — принимай. Если хоть один ❌ — правки или переделка.

---

## Типичные проблемы

### "Тесты зелёные, но изменён лишний файл"
```
Запроси: git diff HEAD~1 [лишний файл]

Если изменение оправдано (например, импорт новой функции) → ✅
Если случайное (форматирование, лог) → ⚠️ правки
```

### "Все файлы изменены, но тесты красные"
```
❌ Переделка

Запроси полный вывод: node --test 2>&1
Укажи Qwen конкретную ошибку из вывода
```

### "В коммите 2 тикета сразу"
```
❌ Откат немедленно

git reset --hard HEAD~1

Объясни Qwen: "Один тикет = один коммит. Делай только T[номер]."
```

## Пример проверки

**Пользователь:** "Qwen закончил T2, вот результат:"
```
git log: a3f8b2c T2: цвета резинок и упражнения 20, 21
node --test: ✔ ... (199 tests)
git diff --stat: src/data.js | 10 +++---
                 src/workout.js | 5 +++
                 src/ui-today.js | 3 ++
```

**Ты (Opus):**
```
Проверяю T2...

✅ Коммит a3f8b2c соответствует формату тикета
✅ Изменены src/data.js, src/workout.js, src/ui-today.js — все из тикета
✅ Нет лишних файлов
✅ 199/199 тестов зелёные

Запрашиваю ключевое изменение:
git diff HEAD~1 src/data.js | grep BAND
```

**Пользователь:** 
```
-var BAND_LEVELS = ['лёгкая', 'средняя', 'тяжёлая'];
+var BAND_COLORS = ['чёрная', 'жёлтая', 'красная', 'зелёная'];
```

**Ты (Opus):**
```
✅ Алгоритм выполнен правильно

---

✅ T2 принят. Коммит a3f8b2c соответствует тикету, тесты зелёные.
Переходи к T3, передай его Qwen.
```
