# ОК — явный вход в правила операционных карт

Запросы `ОК: <задача>` и вызов навыка `ok` запускают этот маршрут.

Перед обработкой приложений обязательно открой и прочитай текущие файлы:

1. [Общий стандарт ОК](../../../docs/standards/operational-cards.md).
2. [Основной навык](../operational-cards/SKILL.md).
3. Если работа идёт через OKConstructor — [адаптер конструктора](../../../docs/standards/operational-cards-okconstructor.md), затем применимый профиль и код.

Читай файлы напрямую. Поиск по памяти не заменяет их и не является условием запуска. В начале работы кратко сообщи, какой стандарт прочитан и какой сценарий выбран: создание ОК, подготовка исходника к считыванию или доработка готовой карты. Не сообщай о чтении до фактического открытия файла.

Если стандарт недоступен, назови недоступный файл и продолжай только независимые действия, для которых правила не нужны. Не обещай применение сохранённых правил по одному названию команды.

Исходником может быть любой предоставленный документ. Прими короткое задание с приложениями, используй шаблон и текущие уточнения пользователя, затем выполни выбранный сценарий по стандарту.

Примеры:

- `ОК: создай карты из приложенных документов по этому шаблону`.
- `ОК: подготовь этот документ для считывания конструктором, добавь ссылочное оглавление`.
- `ОК: заполни пустые изображения в этой готовой карте техническими иллюстрациями`.
