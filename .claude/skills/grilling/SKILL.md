---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

When explicitly invoked as `/grilling`, interview the user through the important
decision branches until there is shared understanding. When used inside System2
`/start`, ask only material unknowns that affect scope, result, cost or access;
stop once a proportionate spec can be agreed. For each question, recommend an
answer and explain the practical effect.

Ask the questions one at a time, waiting for feedback on each question before continuing. Asking multiple questions at once is bewildering.

If a *fact* can be found by exploring the environment (filesystem, tools, etc.), look it up rather than asking me. The *decisions*, though, are mine — put each one to me and wait for my answer.

Do not mark the spec agreed until I confirm the material decisions. In `/start`,
continue to local spec, tickets and handoff in the same dialogue after that
confirmation; do not begin implementation before transfer.
