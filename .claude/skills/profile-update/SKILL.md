# profile-update

Используй единый корень и формат из [memory README](../../.claude/memory/README.md).
Не создавай .system-memory/ и не дублируй записи в другом каталоге.

## Процесс

1. Проанализируй завершённую задачу и выдели только повторяемые предпочтения пользователя,
   а не факты проекта и не собственные решения агента.
2. Покажи пользователю предлагаемую категорию и точный текст; до подтверждения ничего
   не записывай.
3. После «да» запиши frontmatter:
   - прямое подтверждение пользователя → status confirmed, source session with date;
   - гипотеза о предпочтении → status observation до прямого подтверждения;
   - category user-profile, подходящий scope, evidence и при необходимости confidence.
4. При конфликте сохрани прежний текст, новую запись свяжи полем supersedes, а
   прежнюю пометь superseded с обратной ссылкой.
5. Обнови MEMORY.md при добавлении нового файла. Секреты и машинные пути не сохраняй.
6. Сообщи путь, статус и источник; коммит сразу, push после проверки/по указанию.

Не записывай разовые решения, факты проекта или неподтверждённые выводы как
пользовательские предпочтения.
