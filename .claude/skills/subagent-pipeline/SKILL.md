# subagent-pipeline

Процесс и статусы определены в [docs/system-workflow.md](../../../docs/system-workflow.md).

Роли разделены по ответственности:

| Роль | Модель |
|---|---|
| Планировщик и приёмщик | выбирается пользователем/конфигурацией; обычно Opus |
| Автор тикетов | в текущем процессе Sonnet |
| Исполнитель | в текущем процессе GPT Luna через VS Code; для обычного autopilot может быть выбран другой исполнитель |
| Исследование | выбирается по сложности и требованиям источников |

Названия моделей — настройка запуска, не жёсткое ограничение навыка. Один тикет
получает один свежий контекст и один коммит. После каждого результата оркестратор
проводит приёмку; при повторной ошибке останавливает поток и показывает блокер.
