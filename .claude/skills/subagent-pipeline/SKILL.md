# subagent-pipeline

Процесс и статусы определены в [docs/system-workflow.md](../../../docs/system-workflow.md).

Роли разделены по ответственности:

| Роль | Исполнитель роли |
|---|---|
| Планировщик | выбранный пользователем агент; уточняет, планирует, решает архитектуру, не реализует код в этой роли |
| Исполнитель | один выбранный пользователем агент; выполняет разрешённый блок и проверяет результат |
| Приёмщик | выбранный пользователем независимый проверяющий; не принимает собственную реализацию |
| Исследование | выбирается по сложности и требованиям источников |

Названия моделей — настройка запуска, не жёсткое ограничение навыка. Отдельный
обязательный автор тикетов не нужен: тикеты готовит планировщик или исполнитель в тех
же границах.

Исполнитель ведёт связанные тикеты разрешённого блока последовательно в одном рабочем
контексте; один тикет — один scoped-коммит. Новый контекст на каждый тикет не обязателен
и применяется только при реальной причине (например, разросшаяся история или независимая
ветка работы). Сохранять контекст предпочтительно; при переходе в новую сессию нужен
краткий HANDOFF.

Параллельные агенты — явное исключение для независимых задач с обоснованным выигрышем
времени и учётом расходов, а не режим по умолчанию. Приёмку проводит независимый
приёмщик на границе блока; планировщик допустим, если не реализовывал изменение.
Модель проверяющего может совпадать с моделью исполнителя при независимой проверке.
Повторный возврат и обращение при тупике — в
[docs/planner-brief.md](../../../docs/planner-brief.md): тупик выносится планировщику
через пользователя, без runner'а, polling и дополнительных агентов. Какой проверки
достаточно по типу изменения — таблица в
[docs/system-workflow.md](../../../docs/system-workflow.md); успешный набор не
повторяется без нового основания.

## Gotchas

Выбор усилия зависит от сложности, неопределённости и риска и ограничен доступными
настройками клиента; слово `high` в промпте не переключает настройку.
Имя навыка не означает наличия автоматического runner'а: передачу выполняет пользователь.
