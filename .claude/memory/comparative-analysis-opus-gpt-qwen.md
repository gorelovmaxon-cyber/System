# Сравнительный анализ: Opus vs GPT vs Qwen для SystemQwen

**Дата:** 2026-08-16  
**Контекст:** Выбор оптимальной связки моделей для автопилота

## Текущая ситуация пользователя

**Есть сейчас:**
- Opus (планирование, grill, spec, тикеты, ревью)
- Qwen Max (исполнение кода)
- Расход: ~5,000 ₽/мес через API
- Качество: Opus устраивает, Qwen Max "ест лимиты"

**Рассматривается:**
- ChatGPT Plus за ~1,700 ₽/мес (1-3 подписки)
- GPT-5.6 Plus как архитектор
- Дешёвые GPT-модели как исполнители

## Ключевые выводы от другого ИИ

### 1. Главная ошибка: сравнивать цену подписки, а не цену задачи

**Формула правильная:**
```
Стоимость задачи = (Цена модели + Время на переделку × Стоимость часа) / Процент принятых с первого раза
```

**Пример:**
- Дешёвая модель: 10 ₽/задача, но 40% переделок
- Дорогая модель: 45 ₽/задача, но 85% принято

Если переделка = 30 минут = 500 ₽ вашего времени:
```
Дешёвая: 10 + (500 × 0.4) = 210 ₽ реальная стоимость
Дорогая: 45 + (500 × 0.15) = 120 ₽ реальная стоимость
```

### 2. Расход токенов на среднюю задачу

**Типовая задача в автопилоте:**

| Этап | Модель | Input токенов | Output токенов |
|---|---|---|---|
| Plan + Grill + Spec | Сильная | 15,000 | 5,000 |
| Исполнение (1 тикет) | Дешёвая | 8,000 | 3,000 |
| Исполнение (итерации) | Дешёвая | 16,000 | 6,000 |
| Ревью | Сильная | 10,000 | 2,000 |
| **ИТОГО** | — | **49,000** | **16,000** |

**Средняя задача:** ~65k токенов (input+output)

### 3. Примерные API-цены (2026)

**Opus:**
- Input: $15/1M токенов
- Output: $75/1M токенов
- С prompt caching: input падает до ~$1.50/1M

**GPT-5.x (сильные):**
- Input: $10-15/1M
- Output: $30-60/1M

**GPT mini/nano:**
- Input: $0.15-0.40/1M
- Output: $0.60-1.20/1M

**Qwen Max:**
- Input: ~$1.40/1M (через DashScope)
- Output: ~$3.50/1M

**Qwen Coder / Qwen Plus:**
- Input: ~$0.50/1M
- Output: ~$1.50/1M

**Sonnet 5:**
- Input: $3/1M
- Output: $15/1M

## Критические замечания от другого ИИ

### 1. Подписка ≠ API

**ChatGPT Plus проблемы:**
- ❌ Нет стабильного API для автоматизации
- ❌ Лимиты на сообщения/задачи
- ❌ Может нарушать ToS при автоматизации
- ❌ Нет prompt caching
- ❌ Нет batch API
- ❌ Хрупкая интеграция

**Подходит только для:**
- Ручного использования (вставить тикет → скопировать код)
- Экспериментов
- Низкого объёма задач

**Не подходит для:**
- Production-автопилота
- Стабильной автоматизации
- Высокого объёма

### 2. Роль тестов важнее выбора модели

**Лучший ревьюер — автоматика:**
```
1. Линтер
2. Typecheck
3. Unit tests
4. Build
5. Smoke tests
6. Проверка формата diff
```

LLM-ревью нужно только для:
- Архитектуры
- Бизнес-логики
- Безопасности
- Обратной совместимости

### 3. Каскад исполнителей

**Не одна модель для всего, а роутер по сложности:**

```
Простые задачи (30%):
  - Plan: GPT-5.6 (дешёвый)
  - Code: GPT mini
  - Review: автотесты
  - Цена: ~15 ₽

Средние задачи (50%):
  - Plan: Opus
  - Code: GPT mini/Qwen Coder
  - Review: автотесты + GPT-5.6
  - Цена: ~60 ₽

Критичные задачи (20%):
  - Plan: Opus
  - Code: Sonnet 5
  - Review: Opus + автотесты
  - Цена: ~130 ₽
```

**Средневзвешенная цена:**
```
0.3 × 15 + 0.5 × 60 + 0.2 × 130 = 60.5 ₽/задача
```

**Экономия:** ~40% относительно текущих 97 ₽

## Рекомендации для SystemQwen

### Вариант A: Минимальный риск (рекомендую)

**Оставить:**
- Opus для plan/grill/spec/review

**Заменить Qwen Max на:**
- **Qwen Coder** (специализированный для кода)
- Или **GPT mini** (дешевле, если проходит тесты)

**Тестировать:**
- Sonnet 5 для критичных модулей

**Ожидаемая экономия:** 10-20% (500-1,000 ₽/мес)  
**Риск:** Минимальный

### Вариант B: Экономия (если качество ОК)

**Plan/Review:**
- GPT-5.6 Plus (через API)

**Code:**
- GPT mini (простые задачи)
- GPT-5.x (средние задачи)
- Sonnet 5 (критичные задачи)

**Ожидаемая экономия:** 30-40% (1,500-2,000 ₽/мес)  
**Риск:** Средний (нужен benchmark)

### Вариант C: ChatGPT Plus (НЕ рекомендую)

**Проблемы:**
- Нет API для автоматизации
- Лимиты неизвестны
- ToS может запрещать
- Если нужны 2-3 подписки → дороже текущего

**Можно пробовать только:**
- Для ручного использования
- Как дополнение, не замена

### Вариант D: Максимум качества

**Plan/Review:** Opus  
**Code:** Sonnet 5 (всё)

**Цена:** +10-15% (дороже)  
**Качество:** Максимальное  
**Когда:** Критичный код, высокая цена ошибки

## План действий

### Шаг 1: Benchmark (1-2 дня)

**Взять 20 закрытых тикетов:**
- 5 простых
- 10 средних
- 5 сложных

**Прогнать через:**
1. Opus + Qwen Max (baseline)
2. Opus + Qwen Coder
3. Opus + GPT mini
4. Opus + Sonnet 5
5. GPT-5.6 + GPT mini

**Метрики:**
- Принято с первого раза (%)
- Число итераций
- Токены/цена
- Время на переделку
- Сломанные тесты

### Шаг 2: Анализ

**Считать реальную цену:**
```
Цена задачи = API-стоимость + (Время переделки × Стоимость часа) / Процент успеха
```

### Шаг 3: Решение

**Если Qwen Coder или GPT mini проходят 80%+ задач с первого раза:**
→ Менять Qwen Max

**Если Sonnet 5 даёт 95%+ на критичных:**
→ Использовать для важного кода

**Если GPT-5.6 не хуже Opus на plan:**
→ Постепенно переводить план на GPT
