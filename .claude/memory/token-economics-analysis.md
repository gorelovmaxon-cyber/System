# Анализ: Токены vs Эффективность (Персональная память ИИ)

**Дата:** 2026-08-16  
**Контекст:** Обсуждение расширения SystemQwen до полной системы персональной памяти

## Краткий вывод

**Расход токенов увеличивается на 30% в первых 10 проектах, затем падает на 40-60% после 20+ проектов.**

Но реальная экономия — не в токенах, а во времени разработчика (75 часов/год) и качестве решений.

## Фазы внедрения

### Фаза 1: Накопление (проекты 1-10)
- **Расход:** +30-50% токенов
- **Причина:** Чтение памяти, Git-анализ, обновление профиля
- **Польза:** Минимальная (памяти мало)

### Фаза 2: Безубыточность (проекты 10-20)
- **Расход:** ~0% (равен базовому)
- **Причина:** Память начинает окупаться
- **Польза:** Grill сокращается, паттерны переиспользуются

### Фаза 3: Зрелая система (20+ проектов)
- **Расход:** -40-60% токенов
- **Причина:** Готовые паттерны, пропуск вопросов, быстрая spec
- **Польза:** Кратная экономия

## Скрытая экономия (главное)

1. **Время разработчика:** 45 мин/проект × 100 проектов = 75 часов в год
2. **Качество:** Проверенные решения, учёт gotchas
3. **Ошибки:** Память помнит past mistakes → не повторяются

## Стратегия оптимизации токенов

### Умная загрузка (не всё сразу)

**Tier 1 (всегда, 5-10kb):**
- user-profile/coding-style.md
- user-profile/architecture-prefs.md

**Tier 2 (по ключевым словам, 20-50kb):**
- Задача "авторизация" → patterns/jwt-auth.md
- Задача "оплата" → patterns/stripe-payment.md

**Tier 3 (по запросу):**
- Полная история проектов
- Детальные gotchas

### Компрессия через индексы

```markdown
# patterns/index.md (2kb)
- jwt-auth: JWT с refresh tokens, middleware, Redis
- stripe-payment: Webhooks, idempotency, error handling
```

Полный паттерн читается только если нужен.

## Рекомендация: Поэтапное внедрение

### Этап 1 (сейчас): Только user-profile
- Загрузка: 4kb
- Расход: +5% токенов
- Польза: Claude знает стиль

### Этап 2 (через 5 проектов): Добавить patterns
- Загрузка: 6kb
- Расход: +10% токенов
- Польза: Готовые решения

### Этап 3 (через 15 проектов): Полная система
- Загрузка: 8-10kb (умная фильтрация)
- Расход: -20% токенов (экономия начинается)
- Польза: Автопилот на стероидах

## Применимость

✅ **Внедрять, если:**
- 10+ проектов в год
- Повторяющиеся задачи
- Цените время > деньги
- Долгосрочная перспектива

❌ **Не внедрять, если:**
- 1-2 проекта в год
- Каждый проект уникален
- Критична экономия токенов прямо сейчас
