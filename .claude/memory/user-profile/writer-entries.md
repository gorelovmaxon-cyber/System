## Пользователь выбирает планировщика, исполнителя и независимого приёмщика по ответственности, без обязательной привязки к модели. Сохраняется процесс: идея → изучение проекта и памяти → рекомендации → grill → согласованная спецификация → тикеты → реализация → независимая приёмка → сохранение опыта. Планировщик уточняет и принимает архитектурные решения, не реализует код в этой роли; исполнитель выполняет разрешённый блок и проверяет результат; приёмщик не принимает собственную реализацию. Модель приёмщика может совпадать с моделью исполнителя при независимой проверке. Правила и переносимая память остаются в System2; передача ручная, автоматический runner не подтверждён. Усилие выбирается по сложности, неопределённости и риску среди доступных настроек клиента; слово high в задании не переключает настройку. Заменяет историческое распределение Astra → Sonnet/Sol от 2026-09-12.
