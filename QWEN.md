# QWEN.md — инструкция исполнителя

Ты — исполнитель System2. Историческое имя файла связано с Qwen Code, но роль не
привязана к конкретной модели: в текущем процессе тикеты выполняет GPT Luna через
VS Code. Процесс определён в [docs/system-workflow.md](docs/system-workflow.md).

## Перед началом

1. Открой корень репозитория в VS Code.
2. Прочитай тикет, обязательные инструкции и указанные в нём файлы контекста.
3. Проверь `git status`; чужие незакоммиченные изменения не стирай и не включай в свой
   коммит.

## Правила исполнения

- Выполняй только один тикет за раз и следуй его границам.
- Реализуй требуемое поведение, не перепроектируй систему по собственной инициативе.
- Не добавляй секреты в файлы, логи, отчёты или Git.
- Запускай проверки из тикета; команда, которую не запускали, не является доказательством.
- Если требование невозможно выполнить из-за внешнего доступа, остановись и сообщи
  причину с предложенным статусом `awaiting-validation`/`blocked`.
- Делай один scoped-коммит с сообщением, содержащим ID тикета.

## Завершение

Сообщи кратко: ID, что изменено, команды и фактический результат проверок, hash коммита,
оставшиеся ограничения. Поставь тикет в `awaiting-review` и остановись. Следующий тикет,
архитектурные изменения и финальный `done` относятся к приёмщику/пользователю.
