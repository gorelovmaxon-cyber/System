## Как закончить

1. Проверить diff; выполнить проверки; сохранить результаты в отчёте по
   [templates/evidence-report.md](templates/evidence-report.md), включая
   Requirement IDs, сценарии, ограничения и фактические затраты/`unknown`.
2. Создать отдельный коммит с явным списком относящихся к тикету файлов.
   Не включать чужие изменения и не приписывать авторство другой модели.
3. Исполнитель ставит awaiting-review, приёмщик — done только после приёмки.
4. Ответ до 6 строк: ID, результат, проверки, коммит, оставшиеся ограничения, следующий доступный тикет.

**Статусы:** planned → ready-for-agent → in-progress → awaiting-review → done.
awaiting-validation — нет обязательной проверки; blocked — отсутствует необходимая предпосылка.
ready-for-agent ставится только после выполнения зависимостей.
