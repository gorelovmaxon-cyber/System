# Инструкция по использованию SystemQwen

Пошаговое руководство для работы с гибридной системой Opus + Qwen.

## Быстрый старт

**Что вам нужно:**
1. Claude Code с Opus (у вас есть)
2. Qwen Code расширение для VS Code (установить)
3. Qwen API ключ или локальный Qwen Coder (опционально)

**Экономия:** ~5-10× по сравнению с чистым Sonnet

---

## Шаг 1: Подготовка (один раз)

### A) Установить Qwen Code расширение

1. Открой VS Code
2. Extensions (Ctrl+Shift+X)
3. Найди "Qwen Code"
4. Установи официальное расширение от Alibaba
5. Перезапусти VS Code

### B) Подключить Qwen к проекту

**Вариант 1: Qwen API (рекомендуется для старта)**
```bash
# В VS Code открой Command Palette (Ctrl+Shift+P)
> Qwen: Configure API Key
# Вставь ключ от dashscope.aliyuncs.com
```

**Вариант 2: Локальный Qwen через Ollama**
```bash
# Установи Ollama
winget install Ollama.Ollama

# Скачай модель
ollama pull qwen2.5-coder:32b

# В VS Code укажи localhost
> Qwen: Configure Local Server
```

### C) Открой проект в VS Code
```bash
cd d:\треня
code .
```

Qwen Code теперь видит все файлы проекта.

## Шаг 3: Реализация тикета (Qwen)

### A) Открой тикет
```bash
# В VS Code
Ctrl+P → T2-tsveta-rezinok.md
```

### B) Скопируй содержимое тикета

### C) Открой Qwen Chat в VS Code

**Способ 1: Через расширение**
```
Ctrl+Shift+P → Qwen: Open Chat
```

**Способ 2: Боковая панель**
```
Иконка Qwen на левой панели VS Code
```

### D) Вставь в Qwen:

```
Ты работаешь в системе SystemQwen.
Прочитай D:\System2\QWEN.md — это твоя инструкция.

Проект открыт в VS Code: d:\треня

Вот тикет для реализации:

[вставь содержимое T2-tsveta-rezinok.md]

Выполни его полностью и сообщи результат.
```

### E) Qwen работает

Qwen:
1. Прочитает файлы через расширение (src/data.js, src/workout.js...)
2. Напишет код по алгоритму
3. Запустит `node --test`
4. Сделает коммит
5. Ответит:
```
✅ T2 готов
Коммит: a3f8b2c
Тесты: 199/199 зелёные
Изменены: src/data.js, src/workout.js, src/ui-today.js
```

**✋ СТОП.** Qwen больше ничего не делает.

## Шаг 4: Проверка (Opus)

### В терминале (d:\треня):
```bash
git log --oneline -1
node --test
git diff HEAD~1 --stat
```

### В Claude Code (Opus):

```
Проверь результат работы Qwen над T2.

Используй шаблон D:\System2\templates\review-template.md

Вот данные:
[вставь вывод команд выше]
```

**Opus проверит и скажет одно из:**

**A) ✅ Принято:**
```
✅ T2 принят. Коммит a3f8b2c соответствует тикету, тесты зелёные.
Переходи к T3-rezhim-hvata.md
```

**B) ⚠️ Правки:**
```
⚠️ T2 почти готов, нужны правки:
- В src/data.js забыли изменить функцию getBandLevel() на getBandColor()

Передай Qwen: "Исправь в T2: переименуй getBandLevel() → getBandColor()"
```

**C) ❌ Переделка:**
```
❌ T2 не принят. Тесты красные.
git reset --hard HEAD~1
Передай Qwen тикет T2 заново.
```

**✋ СТОП.** Opus больше ничего не делает.

## Типичные ошибки

### ❌ "Opus сразу начал писать код"
**Решение:** Напомни:
```
Стоп! Ты в системе SystemQwen, прочитай D:\System2\OPUS.md
Ты создаёшь только тикеты, код пишет Qwen.
```

### ❌ "Qwen задаёт вопросы вместо выполнения"
**Решение:** Напомни:
```
Стоп! Ты в системе SystemQwen, прочитай D:\System2\QWEN.md
Все ответы в тикете, просто выполняй алгоритм.
```

### ❌ "Qwen сделал T2 и T3 сразу"
**Решение:** Откат:
```bash
git reset --hard HEAD~2
```
Напомни Qwen: "Один тикет = один коммит = одна остановка"

### ❌ "Не знаю, что делать после остановки"
**Решение:** Смотри схему выше. После каждого СТОП — ты принимаешь решение.
