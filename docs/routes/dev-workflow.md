# Маршрут: разработка

Для функций, багов, API и тестов. Общее ядро всегда первое: прочитать `CLAUDE.md`
и HANDOFF проекта. Retrieval выполнять только по условию из
[system-workflow.md](../system-workflow.md#контекст-и-retrieval). Точечные входы для
типовых подсистем — в [task-map.md](../task-map.md).

1. Зафиксировать ожидаемое поведение и границы.
2. Спроектировать минимальное изменение.
3. Реализовать scoped-тикетами/сабагентами.
4. Проверить поведение тестами, ошибки и регрессии.
5. Сохранить commit/HANDOFF/evidence.

Мелкий фикс может идти коротким путём. Дизайн сайта, маркетинг, публикация и
расходы не добавляются без запроса.
