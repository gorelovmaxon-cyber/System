# Маршрут: сайты

Для лендингов и клиентских сайтов. Сначала общее ядро (`CLAUDE.md`/HANDOFF →
retrieval), затем краткий бриф: цель, аудитория, контент, формы и требуемая
аналитика.

1. Согласовать структуру и контент.
2. Подготовить дизайн/реализацию.
3. Выполнить визуальную проверку в браузере; Figma MCP SC-14 использовать
   только при наличии макета и доступа.
4. Проверить формы, доступность и аналитику только если это есть в брифе.
5. Зафиксировать evidence и HANDOFF.

Публикация, домен, реклама и платная аналитика не запускаются автоматически.
