# SystemQwen — Шпаргалка

Быстрый справочник для работы с гибридной системой Opus + Qwen.

## Роли

| Кто | Что делает | Когда останавливается |
|---|---|---|
| **Opus** | Grill → Spec → Tickets → Review | После создания тикетов / После проверки каждого тикета |
| **Qwen** | Читает тикет → Пишет код → Тесты → Коммит | После коммита каждого тикета |
| **Вы** | Оркестрация: передаёте тикеты, запускаете проверку | После каждой остановки — принимаете решение |

## Цикл работы

```
1. Opus: создать тикеты → СТОП
2. Вы: скопировать T2 → Qwen
3. Qwen: реализовать → коммит → СТОП
4. Вы: git log + node --test
5. Opus: проверить → ✅/⚠️/❌ → СТОП
6. Если ✅ → повторить с T3
```

## Команды для проверки

```bash
# После каждого тикета Qwen
git log --oneline -1
node --test
git diff HEAD~1 --stat

# Если нужны правки
git diff HEAD~1 src/data.js

# Если переделка
git reset --hard HEAD~1
```

## Типичные ошибки

| Проблема | Решение |
|---|---|
| Opus пишет код | Напомни: "Прочитай OPUS.md, ты только создаёшь тикеты" |
| Qwen задаёт вопросы | Напомни: "Прочитай QWEN.md, все ответы в тикете" |
| Qwen сделал 2 тикета | `git reset --hard HEAD~2`, напомни про остановки |
| Тесты красные | Запроси `node --test 2>&1`, укажи Qwen ошибку |
| Забыл, что дальше | Смотри "Цикл работы" выше |

## Первый запуск

1. Установи Qwen Code расширение в VS Code
2. Открой проект в VS Code: `cd d:\треня && code .`
3. Попроси Opus создать тикет T2
4. Скопируй T2 → Qwen в VS Code
5. Проверь через Opus
6. Повтори для T3-T5
