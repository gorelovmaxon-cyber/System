# System2 — краткий запуск

Единый процесс: [docs/system-workflow.md](docs/system-workflow.md).

| Роль | Ответственность | Остановка |
|---|---|---|
| Планировщик | grill, spec, план, приёмка | после spec и каждой проверки |
| Автор тикетов (Sonnet) | проверяемые тикеты по [TICKET_TEMPLATE.md](TICKET_TEMPLATE.md) | после нарезки |
| Исполнитель (GPT Luna через VS Code) | один тикет, проверки, один коммит | после `awaiting-review` |
| Пользователь | оркестрация и решения на гейтах | между фазами |

## Цикл

1. Планировщик согласует spec → остановка.
2. Автор тикетов создаёт тикеты → остановка.
3. Исполнитель получает один тикет, реализует и коммитит.
4. Приёмщик проверяет diff и реальные проверки.
5. При успехе следующий тикет; иначе — конкретная доработка.

Правило: один тикет = один коммит = одна остановка. `push` выполняется только после
проверки/по указанию пользователя; force-push и безусловная фоновая синхронизация не
используются.

## Проверка результата

```text
git status
git log --oneline -1
git diff HEAD~1 --stat
```

Команды тестов берутся из конкретного тикета. Не используйте destructive reset для
чужих изменений.
