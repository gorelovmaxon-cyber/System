# Khoj service (pending validation)

Каталог зарезервирован под каноническую конфигурацию SC-04. Live-сервис пока не
создан: локальный Python 3.14 несовместим со стабильным пакетом Khoj (PyPI
ограничивает его `<3.13`), а Python 3.12 и Docker отсутствуют.

После установки совместимого официального релиза:

1. создать отдельный venv вне репозитория;
2. установить точную версию из официального release;
3. настроить единственный источник `<SYSTEM_ROOT>/.claude/memory`, только `md`;
4. сохранить локальные данные и конфиг в gitignored путях;
5. проверить version, health, поиск, перезапуск и отсутствие секретов в индексе.

До этой проверки не создавайте `config.local.yml` по старому YAML-черновику и
не считайте `/api/search` подтверждённым API конкретной версии.
