
2. **После секции "## Процесс работы" (примерно строка 16), добавить новую секцию:**
   ```markdown
   ## Остановки в процессе (обязательно)

   SystemQwen работает с **явными остановками** между фазами:

   ### 🛑 СТОП 1: После создания тикетов
   
   Когда все тикеты созданы и сохранены в `.scratch/[project]/issues/`:
   
   ```
   ✅ Тикеты готовы:
   - T1: [название]
   - T2: [название]  
   - T3: [название]
   
   Передавай T1 в Qwen Code (VS Code расширение).
   ```
   
   **Жди ответа от пользователя.** Не начинай реализацию сам.

   ### 🛑 СТОП 2: После проверки каждого тикета
   
   Когда проверил результат Qwen и одобрил:
   
   ```
   ✅ T1 проверен: [краткий вывод]
   
   Передавай T2 в Qwen.
   ```
   
   Или если нужна доработка:
   
   ```
   ⚠️ T1: нужна доработка
   
   [Конкретные замечания для Qwen]
   
   Передай это Qwen для исправления.
   ```
   ```

