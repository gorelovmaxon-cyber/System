# T8 — Добавить инструкцию про открытие проекта в OPUS.md и TICKET_TEMPLATE.md

**What to build:** Добавить в OPUS.md обязательное правило: каждый тикет должен начинаться с инструкции "Открой VS Code в папке X". Обновить TICKET_TEMPLATE.md с секцией "Перед началом работы".

**Blocked by:** none

**Status:** ready-for-agent

**Перед началом:**
Открой VS Code в папке `D:\System2` (File > Open Folder).

## Контекст

**Файлы для изменения:**
- [D:\System2\OPUS.md](D:\System2\OPUS.md) — инструкция для Opus
- [D:\System2\TICKET_TEMPLATE.md](D:\System2\TICKET_TEMPLATE.md) — шаблон тикета

**Смежные файлы для понимания контекста:**
- [D:\System2\QWEN.md](D:\System2\QWEN.md) — инструкция для Qwen (чтобы понять, почему это критично)
- [D:\System2\issues\T1-opus-explicit-stops.md](D:\System2\issues\T1-opus-explicit-stops.md) — пример тикета с ссылками

**Проблема:**
Qwen работает через расширение VS Code и видит только файлы **открытого проекта**. Если проект открыт в папке `d:\треня`, а тикет ссылается на файлы в `D:\System2\`, Qwen не найдёт их. Это критическая проблема, которая блокирует работу.

**Решение:**
В каждом тикете Opus должен явно указывать, **какую папку открыть в VS Code** перед началом работы.

## Что сделать

- [ ] В OPUS.md добавить правило про обязательную инструкцию по открытию проекта
- [ ] В TICKET_TEMPLATE.md добавить секцию "Перед началом работы"
- [ ] Добавить пример правильного и неправильного тикета в OPUS.md

## Файлы для изменения

- `D:\System2\OPUS.md` — секция "ВАЖНО: Обязательные ссылки на файлы" (после строки 142)
- `D:\System2\TICKET_TEMPLATE.md` — после "Status: ready-for-agent" (строка 7)

## Алгоритм (шаг за шагом)

1. **В `D:\System2\OPUS.md`, после строки 183 (конец секции про ссылки на файлы), добавить:**

   ```markdown
   
   ### Обязательно: Указывай проект для открытия в VS Code
   
   Qwen видит только файлы **открытого проекта** в VS Code. Если тикет работает с файлами из другой папки — Qwen их не найдёт.
   
   **В каждом тикете сразу после "Status: ready-for-agent" добавляй:**
   
   ```markdown
   **Перед началом работы:**
   Открой VS Code в папке `[абсолютный путь к проекту]` (File > Open Folder).
   ```
   
   **Как определить путь:**
   - Если файлы в `D:\System2\` → укажи `D:\System2`
   - Если файлы в `d:\треня\` → укажи `d:\треня`
   - Если файлы в `C:\projects\my-app\` → укажи `C:\projects\my-app`
   
   **Пример плохо:**
   ```markdown
   # T1 — Обновить README
   
   **Status:** ready-for-agent
   
   ## Контекст
   Нужно изменить [README.md](README.md)
   ```
   
   **Пример хорошо:**
   ```markdown
   # T1 — Обновить README
   
   **Status:** ready-for-agent
   
   **Перед началом работы:**
   Открой VS Code в папке `D:\System2` (File > Open Folder).
   
   ## Контекст
   **Файлы для изменения:**
   - [D:\System2\README.md](D:\System2\README.md)
   ```
   
   **Почему это критично:**
   Без этого Qwen потратит время на поиск файлов, не найдёт их и остановится с ошибкой. Эта одна строчка экономит 2-3 минуты на каждый тикет.
   ```

2. **В `D:\System2\TICKET_TEMPLATE.md`, после строки 7 (Status: ready-for-agent), добавить:**

   **Перед началом работы:**
