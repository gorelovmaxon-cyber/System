# SW-04 — сохранение без напоминаний и продолжение с контрольных точек

**What to build:** Работающий агент сохраняет полезное подтверждённое знание
и передачу на границах этапов; новый чат продолжает без старой переписки.
**Requirement IDs:** SW-R4, SW-R5
**Blocked by:** SW-03
**Status:** planned
**Перед началом работы:** E:\\SystemTheBest\\System; читать ../README.md.

## Контекст и изменения
Читать/согласовать docs/system-workflow.md, .claude/skills/auto-learn/SKILL.md,
profile-update/SKILL.md, implement/SKILL.md, handoff/SKILL.md,
systemqwen/SKILL.md, scripts/memory/save.js, writer.js, sync.js, indexer.js.
Использовать существующий writer. Не дублировать алгоритмы в каждом навыке.
В core устранить обязательный старый capture/AP-путь для сохранения знаний.

Контрольные точки: согласованное важное решение, завершённый тикет/блок,
передача другому исполнителю и нормальное завершение сессии.
Явный подтверждённый факт сохраняется без отдельного вопроса «сохранить?».
Вывод агента не становится подтверждённым предпочтением пользователя.
Гипотеза о предпочтении — предложение на подтверждение, не тихая запись confirmed.
Разовый разговор/отсутствие нового знания — допустимый no-op.
Не обещать сохранение после аварийного закрытия до контрольной точки.

## Критерии
- [ ] save.js получает evidence/source/scope/status; результат прочитан и проверен поиском.
- [ ] Повтор той же операции использует прежний event_id и содержимое, не создаёт дубль;
      конфликт не трактуется как успешное сохранение.
- [ ] HANDOFF содержит этап, согласованные решения, ссылки на spec/тикеты,
      сделанное, проверки, остатки и следующий шаг; не дублирует весь чат.
- [ ] Для принятого общего урока есть переносимый источник и разрешённый scope.
- [ ] Включённый Khoj получает обновление индекса через существующий механизм;
      выключенный не порождает постоянные попытки. persisted/synced/indexed различаются.
- [ ] Проверенное знание и передача публикуются работающим исполнителем на границе
      разрешённого блока без повторных просьб; репозитории проекта и System различаются.
- [ ] Нет сети/отказ push: локальное сохранение не потеряно, «не опубликовано» явно;
      нет бесконечных повторов, force или автоматического разрешения конфликтов.
- [ ] Новая сессия без истории чата находит контрольную точку и продолжает нужный этап.
