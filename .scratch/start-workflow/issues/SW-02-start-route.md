## Изменения
Согласовать start, перечисленные навыки и маршрут сайта. Одна каноническая
последовательность в workflow, навыки ссылаются на неё.
Этапы: вход → retrieval → рекомендации с источниками → grill только по
существенному неизвестному → согласование spec → тикеты → пакет передачи.
Память предоставляет SW-03; до его завершения не объявлять рекомендации по прошлым сайтам проверенными.
Spec/тикеты — локальные файлы проекта; внешний трекер только по отдельному решению.
Убрать обязательность чрезмерной спецификации для простой задачи, сохранив критерии.

## Критерии
- [ ] Один стартовый запрос выбирает sites и доводит диалог до пакета передачи
      после ответов пользователя; нет требования по очереди вводить все slash-команды.
- [ ] Рекомендации различают прошлый подтверждённый опыт, новые предложения и неизвестное.
- [ ] Spec фиксирует цель, аудиторию, функции, ограничения, источники, критерии проверки.
- [ ] Тикеты по единому шаблону, с зависимостями и достаточными тестами.
- [ ] Перед реализацией остановка: файл задания, разрешённый блок, HANDOFF,
      выбор Sonnet/Sol; агент не запускает другого агента/чат самостоятельно.
- [ ] Повтор start продолжает сохранённый этап; изменения брифа согласуются,
      старые решения не затираются.
- [ ] Маршруты баг/готовые тикеты не принуждаются к новому длинному интервью.
- [ ] Домен, публикация сайта, платные сервисы и Figma не включаются без разрешения.
