# SW-05 — сквозная приёмка «сайт мороженого» в реальном клиенте

**What to build:** Доказать весь обещанный пользователю маршрут, выпустить
одну короткую инструкцию подключения и ежедневной работы.
**Requirement IDs:** SW-R1…SW-R5
**Blocked by:** SW-01, SW-02, SW-03, SW-04
**Status:** awaiting-validation — инструкция и пакет проверки готовы; полный живой маршрут остановлен API 402, пользовательская передача и независимая приёмка ещё не состоялись
**Перед началом работы:** E:\\SystemTheBest\\System; изолированный демонстрационный
проект вне репозитория, без клиентских данных и без копии SystemTheBest.

## План и данные
Использовать небольшой демонстрационный сайт мороженого, не полноценный клиентский заказ.
Фиктивный бриф/опыт хранить в изолированной тестовой памяти, не канонической.
Исполнитель готовит сценарий; пользователь реально передаёт пакет выбранному
Sonnet/Sol и открывает новую сессию. Без этого live-критерий не засчитывается.
Реальную проверку клиента нельзя заменить исполнением Markdown как shell-команд.
Новый клиент/версия вне проверенного объёма объявляются непроверенными.

## Критерии сквозного сценария
- [ ] Однократное подключение внешней папки, затем один start с брифом.
- [ ] Найден прошлый опыт; показаны рекомендации и их происхождение.
- [ ] Grill использует ответы и приводит к согласованной spec и тикетам.
- [ ] До передачи нет самовольной реализации; пакет достаточен Sonnet/Sol без переписки.
- [ ] После передачи выполнен один небольшой демонстрационный тикет с проверками.
- [ ] На контрольной точке без напоминания сохранены знание и HANDOFF.
- [ ] Независимая проверка реализации не подменена самоприёмкой.
- [ ] Новая сессия без старого чата продолжает сохранённый этап, находит новое знание,
      не повторяет весь grill и не дублирует запись.
- [ ] Khoj и fallback доказаны отдельно по SW-03; секреты/чужой scope не раскрыты.
- [ ] Уже выполненные Git round-trip и restore L06 не повторены без новой причины.
