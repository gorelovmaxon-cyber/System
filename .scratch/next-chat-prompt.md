### Этап 4: Реализация + Review (Sonnet/Qwen → Opus)

**Не для этого чата.** Тикеты будут реализованы отдельно:
- Sonnet или Qwen создаёт файлы по тикетам
- Один тикет = один коммит = один STOP
- Opus (ты) проверяешь каждый результат
- ✅ принимает или ⚠️ доработка

---

## Главные правила для тебя (Opus)

1. **Читай findings как источник наблюдений** — выводы Sonnet требуют проверки по первичным источникам
2. **Не додумывай** — если в findings неясно, спроси (grill)
3. **Explicit stops** — после grill (если нужен), после spec, после tickets
4. **Детальные алгоритмы в тикетах** — Sonnet будет следовать строго
5. **Примеры в тикетах** — покажи формат контента
6. **Не создавай файлы сам** — только spec + tickets, реализация потом
7. **⚠️ КРИТИЧНО: Используй Sonnet для любого анализа файлов** — если нужно прочитать findings или другие файлы, делегируй Sonnet субагенту. Ты (Opus) только для reasoning, не для чтения.
8. **🛑 ОСТАНОВИСЬ ПОСЛЕ ТИКЕТОВ** — твоя работа завершается когда тикеты готовы. НЕ продолжай на реализацию.
