## 1. Характеристики моделей

### Opus 5 (текущая)

**Сильные стороны:**
- ✅ Отличное следование инструкциям
- ✅ Глубокое понимание контекста (1M токенов)
- ✅ Хорошее планирование и декомпозиция
- ✅ Консервативный (задаёт уточняющие вопросы)
- ✅ Интеграция с Claude Code (native)

**Слабые стороны:**
- ❌ Многословность (потратил 140k на тикеты вместо 30k)
- ❌ Дорогой: input $15/1M, output $75/1M
- ❌ Не всегда краток (нужно постоянно напоминать)

**Цена Phase 1-2 (Grill + Spec):**
- Input: ~10k токенов (чтение памяти) = $0.15
- Output: ~20k токенов (вопросы + spec) = $1.50
- **Итого: ~$1.65 за задачу**

---

### GPT-6 Astra (альтернатива)

**Характеристики (на основе публичной информации):**

**Сильные стороны (предполагаемые):**
- ✅ Более лаконичный вывод (меньше "болтовни")
- ✅ Лучшее понимание структуры (лучше декомпозирует задачи)
- ✅ Быстрее генерирует (меньше времени на ответ)
- ✅ Возможно дешевле (цены не известны точно)

**Слабые стороны (потенциальные):**
- ❓ Новая модель — меньше опыта с её поведением
- ❓ Интеграция с Claude Code (нужна адаптация workflow)
- ❓ Context window (неизвестно точно, вероятно 1M+)
- ❓ Качество планирования vs Opus (нужно тестировать)

**Цена Phase 1-2 (предположительно):**
- Если цена ~$10-20/1M output (как GPT-4 Turbo)
- Input: ~10k токенов = $0.05
- Output: ~20k токенов = $0.20-0.40
- **Итого: ~$0.25-0.45 за задачу**

**Экономия: 70-85% vs Opus 5**

## 4. Риски переключения на GPT-6 Astra

### Высокие риски:

1. **Неизвестное поведение:**
   - Opus проверен на 20+ задачах SystemQwen
   - GPT-6 Astra — новая модель, может быть непредсказуемой

2. **Интеграция с Claude Code:**
   - Текущий workflow заточен под Claude (инструменты, скиллы)
   - Нужна адаптация для OpenAI API

3. **Качество Grill:**
   - Opus консервативный, задаёт много вопросов (это хорошо для оркестратора)
   - GPT-6 может быть слишком "самоуверенным", пропустить важные вопросы

### Средние риски:

4. **Следование правилам SystemQwen:**
   - TICKET_TEMPLATE.md, CLAUDE.md — написаны под стиль Opus
   - GPT-6 может интерпретировать иначе

5. **Context handling:**
   - Opus отлично работает с 1M context
   - GPT-6 context window неизвестен точно

### Низкие риски:

6. **Цена может быть выше ожидаемого:**
   - Если OpenAI установит высокую цену на GPT-6
   - Экономия может быть меньше 70%
