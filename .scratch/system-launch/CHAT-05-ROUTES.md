L05-02 (SC-05/15/16): проверить, как оба клиента реально получают контекст. Mandatory instructions/HANDOFF читаются напрямую; Khoj вызывается для нового вопроса, возвращает источники/даты/scope; текущий код читается напрямую при необходимости. На одном коротком задании в GPT и одном в Sonnet проверить поиск прежнего решения и передачу результата. Если второй клиент недоступен тебе — дать пользователю один конкретный smoke-пrompt и оставить клиентскую проверку pending до результата. Не считать написанную инструкцию автоматическим вызовом инструмента. Метрики: фактический объём найденного/прочитанного, число запросов и повторов; кредиты только если доступны, без выдуманных процентов.

L05-03 (SC-14/15): проверить Figma на доступном пользователю реальном файле и nodeId; затем маршруты dev/sites/marketing по соответствующим критериям SPEC. При отсутствии макета/доступа зафиксировать точный незакрытый критерий, не покупать доступ и не выдавать 7/7 fixture за live.
