## Контекст

`config/system.example.json` содержит `indexer.reindex_url: "<CONFIGURE_FROM_KHOJ_RELEASE>"`,
а `scripts/memory/indexer.js` при `reindex()` считает любой 2xx успехом и сразу пишет
`status: indexed`. Задание [CHAT-02-KHOJ.md](../CHAT-02-KHOJ.md) прямо запрещает это:
обычный 2xx, только поставивший индексацию в очередь, не даёт права обещать завершённый
`indexed`. Подтверждение завершения — по реальному API релиза.

Живая задача `idx_175666186629781b` (файл `.claude/memory/facts/writer-entries.md`,
event `evt_system2_acceptance_w1_20260912`) находится в `pending` — это готовый
контролируемый объект проверки, новых тестовых фактов в память писать не нужно.

## Итог

Механизм — `GET http://127.0.0.1:42110/api/update`. Эндпоинт **синхронен**: он
выполняет проход индексации в обработчике и отвечает только после записи эмбеддингов,
подтверждая завершение телом `{"status":"ok"}`. Поэтому 200 здесь означает завершённую
индексацию, а не принятую заявку — но подтверждение берётся из тела, а не из кода
ответа. `indexer.js` ставит `indexed` только после него; 2xx без подтверждения
считается отказом (`did not confirm completion`). Тест
`L02-03: a 2xx that does not confirm completion is not accepted as indexed` это
фиксирует.

Живые проверки:

| Сценарий | Наблюдение |
|---|---|
| Задача на текущую ревизию | `idx_175666186629781b` → `indexed` за 1.576 с, агрегат записи → `indexed:true` |
| Останов (`--stop`) | сервис и postgres остановлены, порт свободен, `postmaster.pid` снят |
| Adapter при выключенном Khoj | `{"ok":false,"error":"khoj-unavailable","fallback":"local",...}`, первая fallback-запись — та же, с верным source и scope |
| Запись при выключенном Khoj | остаётся `persisted` (`indexed:true`) — состояние записи не зависит от сервиса |
| Задача при выключенном Khoj | `idx_d5ed571f4b4cfa3e` → `failed`, причина `fetch failed`, выставлен backoff |
| Возврат Khoj | сервис поднят за ~24 с; индекс сохранён: 19 файлов, полная переиндексация не потребовалась |
| Восстановление | `--requeue-failed` → 1, затем `--run` → `indexed` за один проход |
| Поиск после возврата | тот же результат `ok:true` с source `.claude/memory/facts/writer-entries.md` |

Наборы тестов адаптеров: 64/64 (fix-01, fix-03, fix-07, fix-08).

Команды запуска/остановки/состояния зафиксированы с датой в
