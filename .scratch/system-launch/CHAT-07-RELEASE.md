Проверить remote SHA и восстановимость переносимых файлов. Fresh clone/полный набор нужны при изменении кода после последнего проверенного снимка; для финальной документации достаточно проверки дерева/ссылок/комплектности.

## Готово, когда

Полная READY имеет evidence обязательных live-требований и независимое заключение. В Git опубликованы актуальные код, безопасные конфиги/export, отчёты и HANDOFF; локальные секреты не попали в историю. SHA назначения совпадает с HEAD; оставшиеся намеренные untracked названы явно.

Если Figma, второй ПК или другие обязательные критерии ещё не проверены, можно опубликовать честный промежуточный снимок и пользоваться принятыми частями. Нельзя называть его полной READY или менять SPEC молча ради зелёного статуса. Пользователю дать короткое «работает / не проверено / следующее действие».

Финальный reports/CHAT-07-RESULT.md должен содержать вердикт, release SHA (в ответе после коммита), проверку remote, ссылки на запуск/restore и точные оставшиеся ограничения. Никакого следующего бесконечного этапа улучшений.
