# SITE-BUILD-01 — стандарт сайтов и новая команда

Источник: пользователь в беседе 2026-10-12 одобрил 13 групп правил из опыта
портфолио MAXMADE, попросил задание для System2 и затем передал это задание на
исполнение вложенным текстом «Задание: добавить в System2 команду /site-build
и стандарт создания сайтов». Содержание правил сохранено в
[каноническом стандарте](../../docs/standards/site-creation.md).

## Разрешённый результат

В общей System2 создать стандарт с постоянными ID и разделением качества,
предпочтений и проектных решений; создать навык site-build; подключить start к
нему и далее к существующему autopilot. Правила передаются в спецификацию,
дизайн-систему, адаптивную сетку, тикеты и проверку. Не дублировать autopilot.
Продолжение не повторяет интервью; мелкие правки идут коротким маршрутом;
недоступный поиск не мешает прямому чтению. Соблюдать выбранные роли и режимы.
Код портфолио, другие проекты, локальные секреты и конфигурацию клиентов не менять.

## Проверка результата

13 групп и полнота правил; доступность навыка по структуре System2;
start → site-build → autopilot без цикла; обязательность сетки и дизайн-системы;
доставка правил до исполнения/приёмки; непротиворечивость затронутых инструкций.
Сверить новый сайт, переработку, продолжение, готовые тикеты, мелкую правку и
отказ поиска. В отчёте различать проверку документов и фактическое создание сайта.
Независимую приёмку не приписывать автору реализации.
