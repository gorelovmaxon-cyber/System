# SPEC — тестовый сайт «Мастерская рядом»

Источник: [TASK.md](../../TASK.md), [BRIEF.md](BRIEF.md).
Канонические правила читаются напрямую через `.claude/system2.local.json`:
`<system_root>/docs/standards/site-creation.md`, версия 1, 2026-10-12.
Эта spec содержит решения теста и применимость, а не копию стандарта.
Планирующая роль, systemqwen. Авторизация — прямое делегирование в TASK.md.

## Результат и контент

R1: единственная русскоязычная страница с семантическим main и одним h1.
Название «Мастерская рядом», заголовок «Дайте мебели новую жизнь».
Описание: «Поможем восстановить любимые вещи и сохранить их характер».
Две демонстрационные услуги: «Ремонт мебели» — «Восстановление креплений
и деталей, чтобы мебель снова была удобной»; «Обновление обивки» —
«Замена покрытия мягкой мебели для свежего и аккуратного вида».
Эти тексты — вымышленный контент теста, не реальные факты о компании.

R2: CTA «Посмотреть уведомление» открывает диалог с заголовком
«Тестовый сайт» и точным текстом «Это тестовый сайт. Заявка не отправляется».
Кнопка «Закрыть» закрывает диалог. Открытие с клавиатуры, перемещение фокуса
в диалог, Tab/Shift+Tab внутри, Escape закрывает, фокус возвращается на CTA.
Предпочтителен нативный dialog/showModal с именем через aria-labelledby;
при недоступности — доступная реализация того же поведения без зависимостей.
Никаких полей, отправки, fetch, внешних ссылок и сетевых интеграций.

R3: спокойная контрастная адаптивная композиция. На узком экране естественная
вертикальная прокрутка допустима; «один экран» означает один цельный блок,
а не принудительное сжатие до высоты устройства. Все тексты и открытый диалог
доступны на 320, 375, 768 и 1440 px без горизонтального переполнения.

R4: index.html, styles.css, script.js в корне; без npm-зависимостей, CDN,
внешних шрифтов и картинок. Локальный запуск через Python http.server,
привязанный к 127.0.0.1. README описывает запуск и тестовый характер.

## Визуальное направление и дизайн-система

Тёплый минимальный интерфейс с сильной типографикой и спокойной геометрией.
Внешние референсы не требуются: фото, реальные бренды, орбиты портфолио и
выдуманные социальные доказательства исключены TASK.md.

| Токен/элемент | Решение |
|---|---|
| Фон / поверхность | #F6F3ED / #FFFFFF |
| Основной / вторичный текст | #1D2B24 / #4B5C52 |
| Акцент / текст CTA | #234B38 / #FFFFFF |
| Hover / pressed | #193C2A / #12301F |
| Граница / focus | #BBC7BB / #234B38 (видимое внешнее кольцо с отступом) |
| Шрифт | system-ui, Segoe UI, sans-serif; без внешней загрузки |
| Типографика | h1 clamp(2.25rem, 5vw, 4.5rem), line-height 1.08; h2 1.25rem/1.3; body 1rem/1.6 |
| Интервалы | кратные 8px; 8, 16, 24, 32, 48, 64px |
| Скругления | карточки и диалог 20px; кнопки 16px |
| Карточки | одинаковая структура, внутренние поля 24px, граница 1px |
| Кнопки | primary CTA; secondary закрытие, одинаковая высота не менее 48px |
| Состояния | hover только у hover-устройств, pressed и focus-visible; loading/disabled неприменимы к синхронному уведомлению |

Обе карточки имеют выровненные начала описаний на широком экране.
Заголовок переносится по словам, без жёсткого br на всех экранах.
Контраст подтвердить фактически: обычный текст >= 4.5:1, крупный >= 3:1;
интерактивные границы/фокус различимы. Значения палитры — план, не evidence.

## Адаптивная сетка

Контейнер max-width 1120px, по центру. На 320–639px боковые поля 20px,
внутренние вертикальные поля 32px; порядок: название, h1, описание, услуги,
CTA. Карточки в одну колонку, gap 16px; CTA на всю доступную ширину.
На 640–959px поля 32px, две равные карточки, gap 24px, CTA по содержимому.
От 960px поля 48px и две карточки; h1 ограничен примерно 14ch,
описание 55ch. Верх/низ 64px, без наложений и фиксированных высот текста.
Диалог max-width 480px, width ограничен viewport минус 32px, max-height
viewport минус 32px, overflow-y auto. Backdrop отдельно от содержимого;
декор не используется, слои диалога обеспечивает top layer.

## Анимации, ассеты и границы

Важный контент виден сразу. Только transition background-color 160ms на
кнопках по hover/pressed, без смещения, repeat, задержки или вступления.
При prefers-reduced-motion: reduce — transition отключён. На touch hover
не требуется. Нет циклов, появления/исчезновения, каруселей и анимации скролла.

Предоставлено TASK.md: название и уведомление. Созданы агентом в делегированных
границах: остальные демонстрационные тексты и палитра. Фото/ассеты отсутствуют
по заданию. Шрифт системный. SVG/CSS допустимы, но добавлять их не требуется.
Проверить, что все локальные href/src существуют и запросов наружу нет.

Не требуется: реальные контакты/заказы, формы, аналитика, бекенд, портфолио,
платные API, домен, публикация. Исключений из требований качества нет.
Отказ от заметной анимации — проектное решение спокойного дизайна TASK.md,
а не отмена стандартов анимации там, где эффекты применимы.

## QA и доказательство результата

Достаточная приёмка: локально запущенная страница, браузерные скриншоты
320/375/768/1440 и открытого диалога, отсутствие scrollWidth > clientWidth,
реальные клавиатурные проверки R2, contrast, reduced motion, отсутствие внешних
запросов/ошибок консоли и отдельный независимый вердикт по diff/исходному TASK.
Синтаксис JS отдельно: `node --check script.js`; это не доказательство интерфейса.
Запуск из project: `python -m http.server 8765 --bind 127.0.0.1`.
В браузере `http://127.0.0.1:8765/`. Порт можно изменить при конфликте.
Исполнитель сохраняет реальные команды, наблюдения, скриншоты и матрицу ID
в `EVIDENCE.md` этой папки, без утверждения done/READY.

Браузерная автоматизация подтверждена корневым агентом 2026-10-12.
Корневой агент отвечает за browser QA; исполнитель проверяет корректный
project checkout, синтаксис JS и локальный запуск. Если browser QA недоступен, сохранить awaiting-validation
с причиной; не устанавливать платные/внешние решения. Нативный dialog проверить
до собственной реализации. Пересмотр только при воспроизведённом провале
клавиатуры/доступности; допустим локальный fallback в тех же границах.

Короткая правка выполняется отдельной новой сессией после реализации:
корневой агент передаёт конкретную обратимую правку к этому экрану в тех же
границах. Она использует существующую spec, обновляет затронутые решения и
evidence, проверяет согласованность всех соответствующих элементов, отдельный
scoped-коммит. До конкретной правки новый тикет не выдумывается.

Решение продолжения от 2026-10-12: запрос «Старт: продолжи по HANDOFF.
Сделай все кнопки круглее — радиус16px вместо12px» заменяет исходное решение
12px для обеих кнопок на 16px через общий токен `--radius-button`.
Это локальная обратимая правка DEMO-02; прежние этапы и остальные решения
сохраняются, новое интервью не требуется. Источник — переданное задание
новой сессии в рамках TASK.md.
