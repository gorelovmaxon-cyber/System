# BRIEF — Мастерская рядом

Источник и авторизация: [TASK.md](../../TASK.md), пользователь 2026-10-12.
Разовый изолированный тест SITE-BUILD-04. Дизайнерские решения делегированы
агенту в пределах задания, повторный grill не требуется. Согласование не
выводится из молчания: TASK.md прямо разрешает spec и тестовый цикл.

Цель: показать вымышленную мастерскую ремонта мебели на одном адаптивном
экране и открыть доступное уведомление о тестовом характере сайта.
Аудитория: посетитель, желающий понять, какие виды ремонта мебели предлагает
демонстрационная мастерская. Коммерческие результаты не обещаются.

Обязательные элементы: название, заголовок, короткое описание, две карточки
услуг, кнопка открытия диалога. Реальные заявки, контакты, отзывы, фотографии,
статистические цифры, аналитика, публикация и платные сервисы исключены.
HTML/CSS/JS без внешних зависимостей, только локальный сервер.

Рекомендации до спецификации:
- **Источник:** TASK.md и стандарт `system/docs/standards/site-creation.md`.
  Спокойный контраст и доступность обязательны; палитра другого сайта не наследуется.
- **Источник / ограничение:** memory search дал `ok:false`, Khoj disabled,
  fallback local. Запись user о проверке ассетов имеет status confirmed и source,
  но её первичный внешний отчёт в этом тесте не открывался; это справка,
  не доказательство внешнего факта. Проверять локальные ссылки нужно по QA.
- **Новое предложение:** тёплый светлый фон, глубокий зелёный акцент,
  системные шрифты, простая статичная композиция. Это дизайн теста в
  делегированных границах, а не новое постоянное предпочтение пользователя.
- **Подтверждено корневым агентом 2026-10-12:** Playwright/Chromium доступны.
  Корневой агент отвечает за browser QA; Node v24.14.0 и Python 3.12.10 доступны.

Режим systemqwen: планировщик готовит документы; отдельный исполнитель
реализует разрешённый блок; новая сессия выполняет короткую правку;
отдельный независимый приёмщик проверяет результат. Автоматический runner
не создаётся; файлы в этом тесте передаёт корневой агент по TASK.md.
