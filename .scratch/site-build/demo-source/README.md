# Мастерская рядом

Локальный тестовый сайт вымышленной мастерской. Заявки не отправляются.
Две карточки услуг и кнопка открывают доступное уведомление; Escape или
«Закрыть» закрывают его и возвращают фокус на кнопку открытия.

Из корня проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8765/>. Остановить сервер: Ctrl+C.
HTML/CSS/JS не требуют установки пакетов, внешних шрифтов и сервисов.
Публикация, реальные контакты и отправка заявок в этот тест не входят.

Отдельная проверка синтаксиса: `node --check script.js`.
