# SITE-BUILD-03 — обнаружение в живом клиенте

2026-10-12. Новый Claude Code v2.1.285 запущен в изолированном проекте после
двух идемпотентных `init-project.js --client claude-code`.
Встроенная команда `/skills` фактически показала:

```text
Skills
2 skills
site-build   project · ~30 tok
start        user-only · project · ~20 tok
```

Это наблюдение интерфейса: адаптер зарегистрирован как проектный навык.
Запрос генерации модели через Claude не отправлялся, тест выполнен встроенным
списком навыков; сессия завершена. Применение контракта проверяется отдельно
агентными сессиями в этом чате с файловыми инструментами.
Вариант CLI `--max-budget-usd 0` оказался недопустимым и не запускал генерацию;
после этого использован локальный `/skills` без вызова платного API.
Trust-подтверждение касалось только созданной временной папки; глобальные
настройки навыков, модели и интеграций не редактировались.

Не проверялось: применение `/site-build` моделью Claude через платный API,
автоматическое обнаружение в других клиентских каталогах без setup.
