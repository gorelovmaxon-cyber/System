## Что изменено

**02:** autopilot определяет роль/режим/разрешённый блок до фаз. Убрано
разрешение по таймеру. Планировщик заканчивает передачей; назначенный исполнитель
не возвращается к планированию из-за сохранённого systemqwen. Согласованы
start/site-build/workflow/sites route/operations. Коммит `f62dea3`.

**03:** `init-project.js --client claude-code` создаёт тонкий адаптер site-build
рядом со start. Адаптер читает канонический навык по локальной привязке.
Повторный setup сохраняет инструкции/состояние; конфликтующая пользовательская
команда вызывает отказ до записи проекта/реестра. Коммит `ac18a2d`.
Глобальная регистрация навыков и рабочие клиентские проекты не менялись.

**04:** отдельные агентные контексты прошли планирование, исполнение и продолжение
по файлам на небольшом вымышленном сайте. Исходники и документы сохранены в
[demo-source](demo-source/README.md); полный снимок System2 и локальные конфиги
в репозиторий не включены. Сайт не публиковался на хостинг.
Независимый приёмщик не участвовал в этих фазах.

## Отклонения и исправления в ходе пробы

- Первый расширенный тест входа обнаружил недостаточный PATH Git Bash:
  `date: command not found`. Повтор с Git usr/bin в PATH прошёл19/19, затем полный
  набор209/209. Код hooks не изменялся.
- Проба Claude CLI с `--max-budget-usd 0` отвергнута до генерации. Команда проверена
  через локальный встроенный `/skills`; платный вызов модели Claude не выполнялся.
- В первоначальный снимок ошибочно скопирована вся память System2. Планировщик
  открыл общий facts/writer-entries с другими scope, сообщил это и не использовал
  их в spec. Снимок очищен до единственного разрешённого user-указателя стандарта.
  В исходной System2 чужие записи не изменялись. Архив теста памяти не содержит.
  В site-build добавлена явная инструкция не читать весь смешанный файл по одной
  найденной записи. Это отклонение не скрывается как безупречная изоляция первого захода.
- Планировщик создал полную матрицу86ID для маленького экрана. Стандарт уточнён:
  достаточно применимых ID и обоснованного «неприменимо» по отсутствующим группам;
  одна общая проверка не подтверждает все ID. Полная матрица не требуется каждому тикету.
- Корневой агент уточнял достаточную границу и прерывал избыточную полировку
  передачи в тестовых сессиях. Это управляемая проба с отдельными контекстами,
  не доказательство автономного runner между чатами. История разработки не
  передавалась новой сессии продолжения.
- Независимый приёмщик нашёл две оставшиеся короткие формулировки без различия
  планирования/исполнения (параметр autopilot и usage-guide). Они уточнены; повторная
  сверка требуется только для изменённого текста, сайт не менялся. Он также отдельно
  проверил обе кнопки normal/focus/hover/pressed и консоль: PASS, min contrast5.621,
  console/pageErrors/external пусты; HTTP-хэши файлов и manifest совпадают.

## Ограничения и воспроизведение

Проверен простой статический сайт с доступным уведомлением. Бекенд, отправка
заявок, сложные анимации, внешний хостинг и домены неприменимы к этой пробе.
Slash-команда обнаружена в Claude; выполнение контракта проверено агентами
текущего чата с файловыми инструментами. Генерация сайта через платный Claude API,
другие клиентские интерфейсы и получение изменений на втором ПК не проверялись.
Старые ограничения ROLES не закрываются автоматически.

Для локального просмотра из `demo-source`: `python -m http.server 8766 --bind 127.0.0.1`.
Для повторной QA установленные Playwright/Chromium задаются через
`PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`, адрес через `SITE_TEST_URL`, выходные файлы
через `SITE_TEST_OUTPUT`; затем `node ../evidence/demo-qa.cjs`.
Никаких реальных отправок или внешних запросов тестовый код не делает.
