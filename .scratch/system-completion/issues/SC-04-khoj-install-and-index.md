## Контекст

SPEC R04: «Khoj установлен, индексирует разрешённую память; поиск возвращает источники и ограниченный контекст». Старая документация (docs/khoj-setup.md) предлагала pip/venv без закреплённой версии, маршрут `/api/search` помечен там как непроверенный, а добавление источника — «через веб-интерфейс» (непроверенный шаг). Эти детали нельзя переносить как факт — реальный способ установки, авторизации, конфигурации и API выбирается по официальным источникам выбранного релиза в ENVIRONMENT.md (SC-01) и проверяется в этом тикете живым запуском.

Канонический корень памяти — `.claude/memory/` (SC-02/SC-03); Khoj индексирует только его. Конфиг должен быть воспроизводимым и храниться в `services/khoj/`, данные индекса — вне Git.

## Входные/выходные данные

Вход: каталог памяти `.claude/memory/` (md, рекурсивно); локальный путь `<SYSTEM_ROOT>` из ENVIRONMENT/SC-02. Выход: работающий сервис с HTTP-эндпоинтами; в отчёт — реальные команды и ответы (health + один поиск), версия, дата.

Ожидаемые проверяемые свойства конфигурации:
- источник только `.claude/memory/`, без `.scratch/`, без корневых `.env` и файлов с секретами;
- persistent storage (индекс переживает перезапуск сервиса);
- способ авторизации, выбранный по официальной документации релиза.

## Алгоритм (шаг за шагом)

1. **Установить Khoj** способом из ENVIRONMENT.md (например, venv+pip или официальный установщик выбранного релиза). Зафиксировать версию (`khoj --version`) и сверить с выбранной в SC-01; расхождение — исправить ENVIRONMENT.md с датой.
2. **Определить механизм конфигурации выбранного релиза** по его официальной документации (файловый конфиг/переменные окружения/UI) и создать `services/khoj/config.example.yml` в этом формате (имя — по умолчанию для YAML-механизма; без абсолютных путей: плейсхолдер `${SYSTEM_ROOT}` и комментарий) и `services/khoj/README.md` (шаги генерации локального конфига, запуска и проверки).
3. **Сгенерировать локальный конфиг** (`config.local.yml` при YAML-механизме; иначе — эквивалент выбранного механизма) с реальным абсолютным путём источника (подстановка SYSTEM_ROOT=текущий корень System2). Убедиться, что файл gitignored.
4. **Настроить источники и индексацию** по документации выбранного релиза: только `.claude/memory/`, рекурсивно, md; при наличии механизма исключений — включить его (на случай будущих не-md артефактов в каталоге памяти). Способ авторизации (API key и пр.) — по официальной документации, секрет хранить в gitignored-локальном окружении/конфиге, а не в example.
5. **Запустить сервис**, дождаться готовности, выполнить первоначальную индексацию.
6. **Проверить живой поиск**: запрос по реальной записи памяти (например, термин из `.claude/memory/patterns/explicit-stop-gates.md`) → ответ содержит источник (путь внутри `.claude/memory/`) и ограниченный контекст. Записать команду и ответ в отчёт тикета.
7. **Проверить перезапуск**: остановить и снова запустить сервис; убедиться, что индекс не пересоздаётся с нуля/не теряется (время ответа/наличие результата без полной переиндексации; при необходимости — штатная команда переиндексации).
8. **Проверить исключение секретов**: убедиться, что в индексируемом каталоге нет файлов с реальными ключами, а example-конфиг/коммит не содержат значений секретов. Реальные значения (при необходимости авторизации) — в gitignored локальной настройке с ограниченным доступом, исключённой из индекса; значения не выводятся в логи/отчёт.
9. **Обновить docs/khoj-setup.md** (проверенные шаги/команды/контракт API с датой) и **docs/khoj-integration.md** (фактический API; раздел об адаптере оставить SC-05), дополнить ENVIRONMENT.md фактической версией.
10. **Проверить** сценариями ниже.

## Проверки

**Среда и предпосылки:** локально; установка зависимостей Khoj — часть этой работы (запрета «не устанавливать» больше нет). Docker не обязателен, если выбран не-Docker путь.
**Команды:** точный набор — из README сервиса после его создания; примеры: `khoj --version`, health-curl, поисковый запрос, повтор после перезапуска. Команды, которых ещё нет, помечать «создать в этом тикете».
**Ожидаемый результат:** health 2xx; поиск возвращает источник; перезапуск не теряет индекс; gitignore покрывает локальные файлы.
**Если проверка недоступна:** блокирующая причина (например, нет сети для установки, релиз несовместим с Windows-окружением) → статус blocked в SUMMARY/отчёте с конкретикой; не заменять живой запуск моком.

## Ограничения
