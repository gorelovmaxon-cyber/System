# SC-07 — отчёт исполнителя

Статус: awaiting-review
Дата: 2026-09-08

Реализованы каноническая схема событий, детерминированные event_id с project_id,
ограничение UTF-8 diff, JSONL-очередь вне Git, обработка in-flight после старта,
ограниченные повторы/backoff, HTTP-доставка и CLI capture/status/redeliver.

Проверки:
- commit и session-summary с UTF-8 успешно созданы;
- при недоступном endpoint оба события остались pending, ошибка видна queue-status;
- параллельные capture сохранили обе записи без повреждения JSONL;
- повторный event_id не создал новую логическую запись;
- diff из 30000 кириллических символов усечён до 20002 байт с суффиксом;
- .local покрыт gitignore.

Живой endpoint Activepieces/bridge ещё не существует по зависимостям SC-09/SC-11;
это ожидаемое ограничение, не подмена проверки очереди.

> Уточнение 2026-09-11: прежний результат 20002 байта выявлял дефект B10, а не
> успешное соблюдение лимита 20000. Текущая UTF-8 обрезка не разрывает кодовые
> точки и всегда укладывается в byte limit. Queue получила атомарный claim,
> lease-generation, fail-closed schema validation и recovery оборванного хвоста;
> локальный статус — `awaiting-review`, live доставка — `awaiting-validation`.
